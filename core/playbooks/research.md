# Playbook: research / analysis

## Planning
- Break the question into sub-questions. Plan must include: the questions, the sources/angles you will
  check, the output format (report sections, comparison table, recommendation), and build steps.

## Execution
- Search broadly (several phrasings), open the best sources with fetch_url, prefer primary and recent
  sources, cross-check numbers across at least two sources, and note dates.
- Write REPORT.md: executive summary, findings per sub-question with inline source links, a comparison
  table where useful, risks/unknowns, and a clear recommendation.
- `finish` with the 3–5 sentence spoken summary and where the report is saved.
