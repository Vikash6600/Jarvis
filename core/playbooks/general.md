# Playbook: general task

- Work out what "done" looks like. If the task is small and unambiguous, the plan can be short (a few
  lines) — but still list the steps.
- Use Jarvis's tools (apps, browser, files, web search, messages, reminders, system settings…) and the
  workspace tools. Prefer reversible actions; risky ones will ask the user automatically.
- Report meaningful progress, not every click. `finish` with what was done and anything left for the user.
